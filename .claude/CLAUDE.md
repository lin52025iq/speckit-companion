# Claude Code 中文输出规范

- 默认使用简体中文与用户交流。
- 使用 SpecKit 执行 specify、plan、tasks、implement、clarify、analyze、checklist、constitution 等流程时，所有自然语言输出默认使用简体中文。
- `spec.md`、`plan.md`、`tasks.md`、`research.md`、`data-model.md`、`quickstart.md`、`contracts/`、检查清单、Constitution、Steering 文档及其他说明性 Markdown 默认使用简体中文。
- 代码、Shell 命令、文件路径、API、配置键、标识符、协议字段和技术专有名词保持原文。
- 英文模板与 Skill 指令只作为流程和语义参考，最终面向用户和落盘的自然语言内容应转换为中文。
- 如用户明确指定其他语言，则以用户要求为准。
